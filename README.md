# Планувальник подорожей (Travel Planner)

Екзаменаційний проєкт: Vue 3 + Vite без бекенду. Дані зберігаються в **localStorage** через **Pinia**.

## Технічний стек

| Технологія | Версія / примітка |
|------------|-------------------|
| Vue 3 | Composition API |
| Vite | Збірка |
| Nuxt UI | 4.6.1 (з Vue, без Nuxt) |
| TypeScript | Так |
| Tailwind CSS | v4 |
| Pinia | Стан застосунку |
| localStorage | Персистентність між сесіями |

## Функціонал

- **Подорожі** — назва, країна, дати, статус (планується / активна / завершена)
- **Місця** — список місць у кожній поїздці з відміткою «відвідано»
- **Чекліст** — речі з категоріями (одяг, документи, техніка, інше) + шаблон
- **Статистика** — кількість країн (завершені поїздки), відвідані місця, активні поїздки

## Запуск

```bash
npm install
npm run dev
```

Відкрийте http://localhost:5173

## Збірка

```bash
npm run build
npm run preview
```

## Структура

```
src/
  stores/travel.ts      # Pinia + localStorage
  types/travel.ts       # TypeScript типи
  pages/                # Маршрути (vue-router auto)
  components/           # UI-компоненти
```

## Для здачі екзамену

1. Завантажте репозиторій на GitHub
2. Запишіть коротке відео: створення поїздки → місця → чекліст → статистика → перезавантаження сторінки (дані залишились)
